# 完整网站 UI 重设计原型

预览：/prototypes/full-layout/
用 picker 或 1 / 2 / 3 切换，R 重新加载当前原型。
范围是整页主内容体验，而不只是线条粗细或导航。
阅读长卷现已用于正式首页，正式页面保留 SEO 元数据且不包含 noindex；各原型页面仍保持 noindex。

## 内容约束
档案目录与叙事工作台保留原文。阅读长卷已按用户要求移除“我在做什么”、英语工作语言、“我觉得有意思的 AI 产品”、“工作流”、“实习工作系统”及相应入口；首屏姓名与装饰性小字也已按先前要求移除。其他正文、书籍、链接与封面保留。
调整的是构图、分栏、信息呈现方式和交互。
新增章节编号、快捷入口和项目切换按钮是界面控件，不是新内容。
档案模式部分段落默认折叠，但未删减，且可用键盘展开；无 JS 时原文完整显示。

## 三个方向
1. 阅读长卷：无姓名首屏、侧边 sticky 章节标题、纵向阅读列、封面与笔记并排。
   动效仅用于一次性章节进入和少量按压反馈。适合完整阅读，页面较长。
2. 档案目录：左侧常驻章节索引、紧凑首屏、文件式展开行、小封面双列书单。
   使用原生 details 的键盘行为，指针展开时短时淡入。适合检索，部分内容需要展开。
3. 叙事工作台：大字分屏首屏、空间化章节、横向项目浏览、可触摸滚动书架。
   横向移动由读者控制，支持箭头按钮与键盘。适合探索，部分内容需要横向浏览。

## 动画原则
- 自然纵向滚动，不截获滚轮，不强制整屏翻页。
- 无动画等待状态；正文从一开始可见。
- 动效目的为交互反馈、内容展开、空间定位，而不是装饰。
- 180–260ms 的一次性进入，只动 transform / opacity。
- 按键跳转即时响应，不追加进入动画。
- prefers-reduced-motion 下跳过动态效果，运行中的动画在设置切换时取消。
- 目录支持焦点限制与 Escape，项目横向区域拥有自己的方向键。
- 阅读长卷底色保持 Baby Blue #DCEEF8，文字灰色 #56616B，按钮浅米色 #F3E7D5。
- 正式首页与阅读长卷移除整个浮动进度条和板块滑块，包括百分比、玻璃面板和局部虹彩反馈；其他原型的导航独立保留。
- 白色分隔线与白色高光保持移除；四件原创透明 WebP 材质插画保留，PNG 母版在 assets/prototypes/objects，离线生成脚本为 scripts/render-reader-objects.py。
- 灰色文字替代之前对比度不足的白字；颜色对比度单独检查，不将一般交互测试当作全面可访问性认证。
